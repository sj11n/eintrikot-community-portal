# Länderspiele unserer Mitglieder

Ersetzt die Kennzahl Geförderte Projekte. Automatische Summe aus caps (Länderspiele gesamt) je eindeutigem Mitglied. Jugend-/Altersklassen-Aufschlüsselungen nicht zusätzlich addieren. Nur nichtnegative ganze Zahlen; fehlend ist nicht null Spiele. Ohne erfasste Angaben Gedankenstrich, kein erfundener Wert. Zahl der erfassten Profile intern ausweisen, um Vollständigkeit einschätzen zu können.

Produktion: serverseitige Aggregation über berechtigte aktuelle Mitglieder; ausgeschiedene oder doppelt importierte Datensätze ausschließen. Aggregat öffentlich, keine privaten Einzelwerte über API ausliefern. Nutzung für anonymisierte Vereinsstatistik im Profil-/Datenschutzkonzept transparent erklären. Änderungen am Profil aktualisieren Aggregat/Cache. Individuelle Sichtbarkeit bleibt unabhängig davon erhalten. Keine manuelle Kennzahlüberschreibung.

Vorschau: summiert nur optionale synthetische Testprofilwerte und das eigenständige Vorschauprofil, Kennzeichnung als Testangaben. Kein Bezug zu bestätigten 201 Mitgliedern. Echte Berechnung über WordPress-Datenbank steht aus.
