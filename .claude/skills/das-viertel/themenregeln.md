# Themenregeln für „Das Viertel“

Abgestimmt mit B am 05.11.2026. Grundsatz: Der Newsletter erzählt vom **Netzwerk der Ehemaligen**. Hockey-Nachrichten kommen rein, wenn sie für Ehemalige zählen.

## Rein

| Thema                                                                                     | Rubrik                 |
| ----------------------------------------------------------------------------------------- | ---------------------- |
| Ehemalige in neuen Rollen (Trainerin, Funktionär, Beruf, Ehrenamt)                         | Kurzpass oder Aufmacher |
| Jahrestage von Titeln (aus `Titel-Termine`, `Masters-Termine`)                             | Rückpass               |
| Treffen und Events, bei denen Mitglieder zusammenkommen können (Heimspiele, Kino, Finals) | Spielplan, Kurzpass    |
| **Wichtige** Ergebnisse: Titel und Medaillen der Nationalteams, Auszeichnungen             | Kurzpass               |
| Neue Bundestrainer, Trainerteams, Personalien mit Bezug zu Ehemaligen                      | Kurzpass               |
| Duale Karriere, Stipendien, Förderung                                                      | Kurzpass, Langer Ball  |
| Alumni-Vereine im Feldhockey in Europa (z. B. De Batavieren)                              | Auswärtsspiel          |
| Fundstücke: Video, Foto, Artikel, über die man redet, gern mit Augenzwinkern               | Netzfund               |
| Vereinsnachrichten: Versammlung, Portal, Projekte, Danke                                  | Aus der Kabine         |

Eigene Themen der Redaktion haben immer Vorrang: Porträts („Was macht eigentlich …?“), Gespräche, Vereinsnachrichten.

## Raus

- Reine Ergebnismeldungen ohne Titel, ohne Medaille und ohne Bezug zu Ehemaligen, etwa Ligaspiele oder Vorrunden.
- Aufrufe mit Frist **vor** dem Versanddatum (Votings, Ticketstarts, Anmeldungen). Was dabei herauskam, darf als Ergebnis in den Kurzpass.
- Alles, was nur als Social-Post gedacht ist (Spalte `vorschlag` nennt nur „post“) und für Ehemalige keinen Mehrwert hat.
- Meldungen ohne verlässliche Quelle.
- Interna, die nicht für alle Mitglieder bestimmt sind, Mitgliederdaten und Bank- oder Beitragsdaten.

## Geparkt

Gutes Thema, aber nicht jetzt: zu früh (Event in mehr als sechs Monaten), zu dünn (Quelle folgt), Platz voll. Geparkte Themen legt der Skill bei der nächsten Ausgabe wieder vor.

## Reiter `Newsletter-Plan`

Eine Zeile je Thema. Spalten:

| Spalte           | Inhalt                                                             |
| ---------------- | ------------------------------------------------------------------ |
| `angelegt`       | Datum, an dem die Zeile angelegt wurde (JJJJ-MM-TT)                |
| `quelle`         | `scout` oder `eigen`                                               |
| `scout_datum`    | Datum der Scout-Meldung (leer bei eigenen Themen)                  |
| `titel`          | Kurztitel                                                          |
| `url`            | Quelle (leer bei eigenen Themen)                                   |
| `rubrik`         | Bully, Aufmacher, Kurzpass, Rückpass, Netzfund, Auswärtsspiel, Aus der Kabine, Spielplan |
| `vorschlag`      | rein, raus oder geparkt (Vorschlag des Skills)                     |
| `begruendung`    | ein Satz                                                           |
| `entscheidung`   | rein, raus oder geparkt (Redaktion), leer bis entschieden          |
| `ausgabe`        | z. B. „Nr. 1 · Dezember 2026“                                      |
| `verantwortlich` | wer liefert oder schreibt (Kürzel)                                 |
| `status`         | vorschlag, bestätigt, geschrieben, verwendet                       |
| `notiz`          | frei                                                               |

## Reiter `Ausgaben`

| Spalte          | Inhalt                                               |
| --------------- | ---------------------------------------------------- |
| `nr`            | 1, 2, …                                              |
| `versand`       | Datum                                                |
| `betreff`       | Betreff                                              |
| `aufmacher`     | Format des Aufmachers                                |
| `farbe`         | Rosé, Blau, Grün                                     |
| `mittelteil`    | Reihenfolge, z. B. „Kurzpass, Rückpass, Netzfund“    |
| `rueckpass`     | Jahrestag, z. B. „70 Jahre Melbourne 1956“           |
| `notiz`         | frei                                                 |

## Ergänzung für den Scout (Vorschlag)

Damit Auswärtsspiel und Netzfund Stoff bekommen, kann der Anweisung des Scout-Agenten dieser Absatz angefügt werden. Das passiert nicht automatisch, der Scout ist ein eigenes System.

> Suche zusätzlich einmal pro Woche nach (1) Neuigkeiten von Alumni- und Veteranenvereinen im Feldhockey in Europa, z. B. De Batavieren und vergleichbare Vereine in den Niederlanden, Belgien, England, Spanien, Österreich, mit Kategorie „Alumni Europa“, und (2) Fundstücken rund um ehemalige Nationalspielerinnen und -spieler (Videos, Fotos, Artikel, Podcasts, gern kurios), mit Kategorie „Netzfund“. Trage im Feld `vorschlag` „newsletter“ ein, wenn es für den Vereins-Newsletter passt.
